## Dynamic and behavioral omissions

The source entity partitions contain 24 animated large IMC fans and 3 holospray model props; none has been converted into a working animated target prop. The entity ledger retains all source key/value data for future adapters. No matching target entity is a precise identity result, not an assertion that related brush geometry is absent.

Apex phase travel, animated/interactable doors, original game-mode rules, loot/interaction logic, original scripted movers, source sound/FX behavior and AI/navigation have not been faithfully reproduced. Door blockers were adapted/opened where needed for traversal; the tunnel catwalks and rails are target-authored additions. The technical guide describes lighting, material, sky, collision and visibility approximations.

Historical export audits reporting 54 missing QC/SMD meshes predate direct compiled VG recovery. They must not be quoted as the current release omission count. The static ledger is reconciled against the latest fir recovery inventory; dynamic, outside-arena and behavioral omissions are counted separately.
