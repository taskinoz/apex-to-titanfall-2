# Remaining source objects after 0.1.46

The map renders 5,425 of 16,376 arena static prop placements.
10,951 placements across 68 model types remain omitted.
9,537 are vegetation and 1,414 are other categories.
This release restores twenty original full-sized fir placements, replacing the shrub-sized acacias from 0.1.45. The 486 placements
outside the imported arena and dynamic entities remain separate inventories.
